# TurtleBot3 SLAM 仿真通信流关系文档

> 本文档详细描述了 TurtleBot3 SLAM 仿真系统中各 ROS2 节点之间的通信流关系，包括 Topic、消息数据结构、Service 及作用。

---

## 一、系统架构概览

系统由 **四大模块** 组成：

| 模块 | 说明 |
|------|------|
| **Gazebo 仿真环境** | 提供物理仿真、传感器数据生成、ROS-Gazebo 桥接 |
| **TurtleBot3 节点** | 负责运动控制（自动避障/键盘遥控/仿真里程计） |
| **SLAM Toolbox** | 负责激光 SLAM 建图与定位 |
| **RViz2** | 负责可视化（地图、姿态图、激光点云等） |

## 二、节点清单与详细通信关系

### 2.1 Gazebo 仿真环境节点

#### 2.1.1 `ros_gz_bridge` (parameter_bridge)

| 属性 | 值 |
|------|-----|
| **包** | `ros_gz_bridge` |
| **类型** | 双向桥接节点 |
| **作用** | 将 Gazebo 内部传感器数据转换为 ROS2 话题，并将 ROS2 控制指令转发给 Gazebo |

**桥接的 Topic 清单**：

| ROS Topic | ROS 消息类型 | Gazebo Topic | 方向 | 说明 |
|-----------|-------------|--------------|------|------|
| `/clock` | `rosgraph_msgs/msg/Clock` | `clock` | GZ → ROS | 仿真时钟，所有节点设置 `use_sim_time=true` 时使用 |
| `/joint_states` | `sensor_msgs/msg/JointState` | `joint_states` | GZ → ROS | 左右轮关节状态 |
| `/odom` | `nav_msgs/msg/Odometry` | `odom` | GZ → ROS | Gazebo 物理引擎计算的里程计 |
| `/tf` | `tf2_msgs/msg/TFMessage` | `tf` | GZ → ROS | Gazebo 内部 TF 变换 |
| `/cmd_vel` | `geometry_msgs/msg/TwistStamped` | `cmd_vel` | ROS → GZ | 速度指令，控制机器人运动 |
| `/imu` | `sensor_msgs/msg/Imu` | `imu` | GZ → ROS | IMU 传感器数据 |
| `/scan` | `sensor_msgs/msg/LaserScan` | `scan` | GZ → ROS | LDS 激光雷达数据 |
| `/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | `camera/camera_info` | GZ → ROS | 相机内参（非 Burger 模型） |

**消息数据结构**：

```protobuf
// sensor_msgs/msg/LaserScan
Header header           # 时间戳和坐标系
float32 angle_min       # 起始角度 (rad)
float32 angle_max       # 结束角度 (rad)
float32 angle_increment # 角度增量 (rad)
float32 time_increment  # 时间增量 (s)
float32 scan_time       # 扫描周期 (s)
float32 range_min       # 最小测距 (m)
float32 range_max       # 最大测距 (m)
float32[] ranges        # 距离数组 (m)，inf 表示无障碍
float32[] intensities   # 强度数组
```

```protobuf
// nav_msgs/msg/Odometry
Header header
string child_frame_id
PoseWithCovariance pose     # 位姿 + 6x6 协方差矩阵
TwistWithCovariance twist   # 速度 + 6x6 协方差矩阵
```

```protobuf
// geometry_msgs/msg/TwistStamped
Header header
Twist twist
  Vector3 linear    # linear.x = 线速度 (m/s)
  Vector3 angular   # angular.z = 角速度 (rad/s)
```

```protobuf
// sensor_msgs/msg/Imu
Header header
Quaternion orientation      # 四元数姿态
Vector3 angular_velocity    # 角速度 (rad/s)
Vector3 linear_acceleration # 线加速度 (m/s²)
```

### 2.2 TurtleBot3 运动控制节点

#### 2.2.1 `turtlebot3_drive_node` (自动避障/探索)

| 属性 | 值 |
|------|-----|
| **包** | `turtlebot3_gazebo` |
| **源文件** | `src/turtlebot3_drive.cpp` |
| **作用** | 基于激光雷达数据的自主避障和探索驱动，实现 SLAM 自动建图 |

**订阅 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/scan` | `sensor_msgs/msg/LaserScan` | SensorDataQoS | 激光雷达数据，用于障碍物检测 |
| `/odom` | `nav_msgs/msg/Odometry` | KeepLast(10) | 里程计数据，获取当前偏航角 |

**发布 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/cmd_vel` | `geometry_msgs/msg/TwistStamped` | KeepLast(10) | 速度指令，控制机器人运动 |

**内部状态机**：

```
GET_TB3_DIRECTION (0)
    ├── 前方开阔 (inf_ratio > 0.7) → TB3_DRIVE_FORWARD
    │   └── 直行 30 次后 → 转向探索
    ├── 前方安全 (front_avg_dist > 1.2m) → 检查侧方
    │   ├── 左侧过近 → TB3_RIGHT_TURN
    │   ├── 右侧过近 → TB3_LEFT_TURN
    │   └── 两侧安全 → TB3_DRIVE_FORWARD
    └── 前方有障碍 → 比较左右距离
        ├── 左侧更开阔 → TB3_LEFT_TURN
        └── 右侧更开阔 → TB3_RIGHT_TURN
```

**关键参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `LINEAR_VELOCITY` | 0.3 m/s | 直行线速度 |
| `ANGULAR_VELOCITY` | 1.5 rad/s | 转向角速度 |
| `escape_range` | 30° | 转向角度阈值 |
| `check_forward_dist` | 1.2 m | 前方安全距离 |
| `check_side_dist` | 1.0 m | 侧方安全距离 |
| `inf_ratio` | 0.7 | 激光射线检测不到障碍的比例阈值 |

**更新频率**：10ms (100 Hz)

#### 2.2.2 `turtlebot3_fake_node` (仿真里程计)

| 属性 | 值 |
|------|-----|
| **包** | `turtlebot3_fake_node` |
| **源文件** | `src/turtlebot3_fake_node.cpp` |
| **作用** | 在没有 Gazebo 时提供仿真的里程计和关节状态（独立于 Gazebo 时使用） |

**订阅 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/cmd_vel` | `geometry_msgs/msg/Twist` 或 `TwistStamped` | KeepLast(10) | 速度指令（由参数 `enable_stamped_cmd_vel` 决定类型） |

**发布 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/odom` | `nav_msgs/msg/Odometry` | KeepLast(10) | 仿真里程计（运动学积分计算） |
| `/joint_states` | `sensor_msgs/msg/JointState` | KeepLast(10) | 左右轮关节状态 |
| `/tf` | `tf2_msgs/msg/TFMessage` | KeepLast(10) | odom → base_footprint 变换 |

**差速驱动运动学模型**：

```cpp
// 速度分解
wheel_speed_cmd[LEFT]  = goal_linear_velocity - (goal_angular_velocity * wheel_separation / 2)
wheel_speed_cmd[RIGHT] = goal_linear_velocity + (goal_angular_velocity * wheel_separation / 2)

// 里程计积分
delta_s = wheel_radius * (wheel_r + wheel_l) / 2.0        // 前进距离
delta_theta = wheel_radius * (wheel_r - wheel_l) / wheel_separation  // 转向角度

// 位姿更新
x += delta_s * cos(theta)
y += delta_s * sin(theta)
theta += delta_theta
```

**关键参数**（由 YAML 配置文件提供）：

| 参数 | Burger | Waffle/Waffle Pi | 说明 |
|------|--------|-------------------|------|
| `wheels.separation` | 0.160 m | 0.287 m | 左右轮间距 |
| `wheels.radius` | 0.033 m | 0.033 m | 轮子半径 |
| `joint_states_frame` | base_footprint | base_footprint | 关节状态帧 ID |
| `odom_frame` | odom | odom | 里程计帧 ID |
| `base_frame` | base_footprint | base_footprint | 基座帧 ID |

**更新频率**：10ms (100 Hz)
**cmd_vel 超时**：1.0 秒无指令则自动停止

### 2.3 SLAM Toolbox 节点

#### 2.3.1 `async_slam_toolbox_node` (异步 SLAM)

| 属性 | 值 |
|------|-----|
| **包** | `slam_toolbox` |
| **节点名** | `slam_toolbox` |
| **类型** | `rclcpp_lifecycle::LifecycleNode` |
| **作用** | 基于激光雷达和里程计数据进行 2D SLAM 建图，发布地图和位姿 |

**订阅 Topic**：

| Topic | 消息类型 | 说明 |
|-------|----------|------|
| `/scan` | `sensor_msgs/msg/LaserScan` | 激光雷达扫描数据（通过 `message_filters` + `tf2_ros::MessageFilter` 订阅） |

**发布 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/map` | `nav_msgs/msg/OccupancyGrid` | TRANSIENT_LOCAL, KeepLast(1) | 占用栅格地图 |
| `/map_metadata` | `nav_msgs/msg/MapMetaData` | TRANSIENT_LOCAL, KeepLast(1) | 地图元数据 |
| `pose` | `geometry_msgs/msg/PoseWithCovarianceStamped` | TRANSIENT_LOCAL, KeepLast(1) | 机器人校正后位姿 |
| `slam_toolbox/pose_graph` | `slam_toolbox/msg/PoseGraph` | TRANSIENT_LOCAL, KeepLast(1) | 姿态图（节点+边） |
| `slam_toolbox/new_node_event` | `slam_toolbox/msg/NewNodeEvent` | KeepLast(10) | 新节点添加事件 |
| `slam_toolbox/loop_closure_event` | `slam_toolbox/msg/LoopClosureEvent` | KeepLast(10) | 回环检测事件 |
| `/tf` | `tf2_msgs/msg/TFMessage` | — | map → odom 变换（`transform_publish_period=0.02s`） |

**提供的 Service**：

| Service | 服务类型 | 说明 |
|---------|----------|------|
| `slam_toolbox/dynamic_map` | `nav_msgs/srv/GetMap` | 获取当前地图 |
| `slam_toolbox/serialize_map` | `slam_toolbox/srv/SerializePoseGraph` | 序列化姿态图到文件 |
| `slam_toolbox/deserialize_map` | `slam_toolbox/srv/DeserializePoseGraph` | 从文件加载姿态图 |
| `slam_toolbox/pause_new_measurements` | `slam_toolbox/srv/Pause` | 暂停/恢复接收新数据 |
| `slam_toolbox/reset` | `slam_toolbox/srv/Reset` | 重置地图 |

**核心自定义消息结构**：

```protobuf
// slam_toolbox/msg/PoseGraph
Header header
GraphNode[] nodes     # 姿态图顶点列表
GraphEdge[] edges     # 姿态图边列表
```

```protobuf
// slam_toolbox/msg/GraphNode
int32 node_id
Pose pose             # 顶点位姿 (x, y, z, quaternion)
```

```protobuf
// slam_toolbox/msg/GraphEdge
int32 source_id       # 源节点 ID
int32 target_id       # 目标节点 ID
Pose relative_pose    # 相对位姿约束
float64[9] covariance # 3x3 协方差矩阵（行优先）
```

```protobuf
// slam_toolbox/msg/NewNodeEvent
int32 new_node_id
builtin_interfaces/Time stamp
Pose pose
GraphEdge edge        # 连接到姿态图的边
```

```protobuf
// nav_msgs/msg/OccupancyGrid
Header header
MapMetaData info
  float32 map_load_time
  float32 resolution      # 地图分辨率 (m/px)，默认 0.05
  uint32 width            # 地图宽度 (px)
  uint32 height           # 地图高度 (px)
  Pose origin             # 地图原点位姿
int8[] data             # 像素值: -1(未知), 0(空闲), 100(占用)
```

```protobuf
// geometry_msgs/msg/PoseWithCovarianceStamped
Header header
PoseWithCovariance pose
  Pose pose               # 位姿
  float64[36] covariance  # 6x6 协方差矩阵
```

**关键参数**（来自 `mapper_params_online_async.yaml`）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `scan_topic` | `/scan` | 激光扫描话题 |
| `odom_frame` | `odom` | 里程计坐标系 |
| `map_frame` | `map` | 地图坐标系 |
| `base_frame` | `base_footprint` | 机器人基坐标系 |
| `resolution` | 0.05 | 地图分辨率 (m/px) |
| `map_update_interval` | 5.0 | 地图更新间隔 (s) |
| `transform_publish_period` | 0.02 | map→odom TF 发布周期 (s) |
| `throttle_scans` | 1 | 每 N 帧处理一次 |
| `use_scan_matching` | true | 是否使用扫描匹配 |
| `do_loop_closing` | true | 是否执行回环检测 |
| `minimum_travel_distance` | 0.5 | 触发建图的最小移动距离 (m) |
| `minimum_travel_heading` | 0.5 | 触发建图的最小旋转角度 (rad) |
| `max_laser_range` | 20.0 | 最大激光范围 (m) |
| `enable_interactive_mode` | true | 是否启用 RViz 交互式回环 |
| `solver_plugin` | `solver_plugins::CeresSolver` | 优化器插件 |

**处理流程**：

```
LaserScan 回调
    ↓
通过 MessageFilter 获取匹配的 TF
    ↓
扫描匹配（相对于最近的关键位姿）
    ↓
添加到姿态图（Pose Graph）
    ↓
回环检测（距离阈值 loop_search_maximum_distance=3.0m）
    ↓
优化姿态图（Ceres Solver）
    ↓
发布 /map, pose, pose_graph, TF(map→odom)
```

## 三、坐标系 (TF) 关系

```
                    map (SLAM 发布)
                     │
                     │ map → odom TF
                     │ (由 SLAM 校正)
                     ▼
                    odom (Gazebo 或 FakeNode 发布)
                     │
                     │ odom → base_footprint TF
                     │ (由物理引擎或运动学积分)
                     ▼
               base_footprint
                     │
        ┌────────────┼────────────┐
        │            │            │
        ▼            ▼            ▼
   base_link   imu_link    base_scan
        │                              ← LDS 激光雷达坐标系
   wheel_left
   wheel_right
   caster_back
```

| TF 变换 | 发布者 | 说明 |
|---------|--------|------|
| `map → odom` | `slam_toolbox` | SLAM 校正的全局位姿变换 |
| `odom → base_footprint` | Gazebo / `turtlebot3_fake_node` | 里程计累积的局部位姿 |
| `base_footprint → base_link` | `robot_state_publisher` | 底盘主体位置 |
| `base_link → base_scan` | `robot_state_publisher` | 激光雷达安装位置 |
| `base_link → imu_link` | `robot_state_publisher` | IMU 安装位置 |
| `base_link → wheel_left/right_link` | `robot_state_publisher` | 轮子位置 |

## 四、典型工作流通信时序

### 4.1 自动 SLAM 建图流程 (`auto_slam.launch.py`)

```
时间线:
─────────────────────────────────────────────────────────────────────

T+0s    Gazebo 启动
        ├── Gazebo Sim 开始物理仿真
        ├── ros_gz_bridge 开始桥接话题
        │   ├── /scan ← GZ LaserScan
        │   ├── /odom ← GZ Odometry
        │   ├── /tf   ← GZ Pose_V
        │   └── /clock ← GZ Clock
        └── robot_state_publisher 发布静态 TF

T+0s    slam_toolbox 启动 (LifecycleNode)
        ├── 进入 UNCONFIGURED 状态
        ├── 加载 mapper_params_online_async.yaml
        ├── TRANSITION_CONFIGURE → CONFIGURED
        └── TRANSITION_ACTIVATE → ACTIVE（开始处理 /scan）

T+3s    turtlebot3_drive_node 启动
        ├── 订阅 /scan (LaserScan)
        ├── 订阅 /odom (Odometry)
        └── 发布 /cmd_vel (TwistStamped)

        ┌─────────────────────────────────────────────────────┐
        │  持续循环 (100Hz):                                   │
        │  1. scan_callback: 解析激光数据，计算前/左/右距离     │
        │  2. odom_callback: 更新偏航角                        │
        │  3. update_callback: 状态机决策 → 发布 cmd_vel       │
        └─────────────────────────────────────────────────────┘
                │
                ▼ /cmd_vel (TwistStamped)
        Gazebo 接收 → 物理仿真 → 更新位姿 → /odom, /scan 更新
                │
                ▼ /scan (LaserScan)
        SLAM Toolbox 接收 → 扫描匹配 → 更新姿态图
                │
                ▼ 发布
        /map, pose, pose_graph, TF(map→odom)
                │
                ▼
        RViz2 显示

─────────────────────────────────────────────────────────────────────
```

### 4.2 键盘遥控 SLAM 建图流程

```
用户按键 (w/a/s/d)
        │
        ▼
turtlebot3_teleop_keyboard

        ▼
/scan, /odom 更新
        │
        ▼

        │
        ▼
RViz2 显示
```

## 五、Service 调用关系汇总

| 调用方 | Service | 服务提供方 | 服务类型 | 用途 |
|--------|---------|------------|----------|------|

## 六、QoS 策略汇总

| Topic | QoS 策略 | 原因 |
|-------|----------|------|
| `/scan` | SensorDataQoS | 传感器数据，使用 `SensorDataQoS` (KeepLast, 短深度) |
| `/odom` | KeepLast(10) | 里程计数据，需要最近历史 |
| `/cmd_vel` | KeepLast(10) | 控制指令，需要最近历史 |

| `/map_metadata` | TRANSIENT_LOCAL + KeepLast(1) | 新订阅者需要立即获取元数据 |
| `pose` | TRANSIENT_LOCAL + KeepLast(1) | 新订阅者需要立即获取位姿 |
| `slam_toolbox/pose_graph` | TRANSIENT_LOCAL + KeepLast(1) | 新订阅者需要立即获取姿态图 |
| `slam_toolbox/new_node_event` | KeepLast(10) | 事件通知，保留最近 10 条 |
| `slam_toolbox/loop_closure_event` | KeepLast(10) | 事件通知，保留最近 10 条 |
