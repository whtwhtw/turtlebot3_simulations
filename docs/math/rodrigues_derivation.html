罗德里格斯公式：旋转向量 → 旋转矩阵

给定旋转向量：$\theta\mathbf{u} = \dfrac{\pi}{4}(0,\,0,\,1)^{\mathsf{T}}$，即：

旋转角度：$\theta = \dfrac{\pi}{4}$（45°）
旋转轴：$\mathbf{u} = (0,\,0,\,1)^{\mathsf{T}}$（已是单位向量，表示绕 Z 轴旋转）

一、罗德里格斯公式

$$R = I + \sin\theta \cdot K + (1 - \cos\theta) \cdot K^2$$

其中 $K$ 是单位向量 $\mathbf{u} = (u_x, u_y, u_z)^{\mathsf{T}}$ 的反对称矩阵：

$$K = \begin{bmatrix} 0 & -u_z & u_y \\ u_z & 0 & -u_x \\ -u_y & u_x & 0 \end{bmatrix}$$

代入 $\mathbf{u} = (0, 0, 1)^{\mathsf{T}}$：

$$K = \begin{bmatrix} 0 & -1 & 0 \\ 1 & \;\;0 & 0 \\ 0 & \;\;0 & 0 \end{bmatrix}$$

二、详细计算步骤

Step 1：计算 $K^2$

$$K^2 = K \cdot K = \begin{bmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix} \begin{bmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix}$$

逐元素计算：

  • $K^2_{11} = 0 \times 0 + (-1) \times 1 + 0 \times 0 = \mathbf{-1}$
  • $K^2_{12} = 0 \times (-1) + (-1) \times 0 + 0 \times 0 = \mathbf{0}$
  • $K^2_{21} = 1 \times 0 + 0 \times 1 + 0 \times 0 = \mathbf{0}$
  • $K^2_{22} = 1 \times (-1) + 0 \times 0 + 0 \times 0 = \mathbf{-1}$
  • 第三行/列全为 0

$$K^2 = \begin{bmatrix} -1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 0 \end{bmatrix}$$

Step 2：计算三角函数值

  • $\sin\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2} \approx \mathbf{0.7071}$
  • $\cos\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2} \approx \mathbf{0.7071}$
  • $1 - \cos\dfrac{\pi}{4} = 1 - \dfrac{\sqrt{2}}{2} \approx \mathbf{0.2929}$

Step 3：代入公式，逐项相加

第一项（单位矩阵）：

$$I = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

第二项（$\sin\theta \cdot K$）：

$$\sin\theta \cdot K = \frac{\sqrt{2}}{2} \begin{bmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix} = \begin{bmatrix} 0 & -\frac{\sqrt{2}}{2} & 0 \\[6pt] \frac{\sqrt{2}}{2} & 0 & 0 \\[6pt] 0 & 0 & 0 \end{bmatrix}$$

第三项（$(1-\cos\theta) \cdot K^2$）：

$$(1 - \cos\theta) \cdot K^2 = \left(1 - \frac{\sqrt{2}}{2}\right) \begin{bmatrix} -1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 0 \end{bmatrix} = \begin{bmatrix} -1 + \frac{\sqrt{2}}{2} & 0 & 0 \\[6pt] 0 & -1 + \frac{\sqrt{2}}{2} & 0 \\[6pt] 0 & 0 & 0 \end{bmatrix}$$

Step 4：合并三个矩阵

$$R = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} + \begin{bmatrix} 0 & -\frac{\sqrt{2}}{2} & 0 \\[6pt] \frac{\sqrt{2}}{2} & 0 & 0 \\[6pt] 0 & 0 & 0 \end{bmatrix} + \begin{bmatrix} -1 + \frac{\sqrt{2}}{2} & 0 & 0 \\[6pt] 0 & -1 + \frac{\sqrt{2}}{2} & 0 \\[6pt] 0 & 0 & 0 \end{bmatrix}$$

逐元素相加：

  • $R_{11} = 1 + 0 + \left(-1 + \frac{\sqrt{2}}{2}\right) = \mathbf{\frac{\sqrt{2}}{2}}$
  • $R_{12} = 0 + \left(-\frac{\sqrt{2}}{2}\right) + 0 = \mathbf{-\frac{\sqrt{2}}{2}}$
  • $R_{21} = 0 + \frac{\sqrt{2}}{2} + 0 = \mathbf{\frac{\sqrt{2}}{2}}$
  • $R_{22} = 1 + 0 + \left(-1 + \frac{\sqrt{2}}{2}\right) = \mathbf{\frac{\sqrt{2}}{2}}$
  • $R_{33} = 1 + 0 + 0 = \mathbf{1}$
  • 其余元素均为 0

三、最终结果

$$R = \begin{bmatrix} \frac{\sqrt{2}}{2} & -\frac{\sqrt{2}}{2} & 0 \\[8pt] \frac{\sqrt{2}}{2} & \frac{\sqrt{2}}{2} & 0 \\[8pt] 0 & 0 & 1 \end{bmatrix} \approx \begin{bmatrix} 0.7071 & -0.7071 & 0 \\ 0.7071 & \;\;0.7071 & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

✓ 验证：这正是绕 Z 轴旋转 45° 的标准旋转矩阵 $R_z\!\left(\dfrac{\pi}{4}\right)$，与预期完全一致！
💡 物理意义：旋转向量 $(\theta, \mathbf{u})$ 表示绕单位轴 $\mathbf{u}$ 旋转 $\theta$ 角度，罗德里格斯公式将其转换为等价的 3×3 旋转矩阵。
