# TurtleBot3 SLAM 仿真通信流关系文档

> 本文档详细描述了 TurtleBot3 SLAM 仿真系统中各 ROS2 节点之间的通信流关系，包括 Topic、消息数据结构、Service 及作用。

---

## 一、系统架构概览

系统由 **四大模块** 组成：

| 模块 | 说明 |
|------|------|
| **Gazebo 仿真环境** | 提供物理仿真、传感器数据生成、ROS-Gazebo 桥接 |
| **TurtleBot3 节点** | 负责运动控制（自动避障/键盘遥控/仿真里程计） |
| **SLAM Toolbox** | 负责激光 SLAM 建图与定位 |
| **DQN 强化学习** | 基于 TensorFlow 的 Deep Q-Network，实现自主导航避障训练 |
| **RViz2** | 负责可视化（地图、姿态图、激光点云等） |

#### 2.1.1 `ros_gz_bridge` (parameter_bridge)

| 属性 | 值 |
|------|-----|
| **包** | `ros_gz_bridge` |
| **类型** | 双向桥接节点 |
| **作用** | 将 Gazebo 内部传感器数据转换为 ROS2 话题，并将 ROS2 控制指令转发给 Gazebo |

**桥接的 Topic 清单**：

| ROS Topic | ROS 消息类型 | Gazebo Topic | 方向 | 说明 |
|-----------|-------------|--------------|------|------|
| `/clock` | `rosgraph_msgs/msg/Clock` | `clock` | GZ → ROS | 仿真时钟，所有节点设置 `use_sim_time=true` 时使用 |
| `/joint_states` | `sensor_msgs/msg/JointState` | `joint_states` | GZ → ROS | 左右轮关节状态 |
| `/odom` | `nav_msgs/msg/Odometry` | `odom` | GZ → ROS | Gazebo 物理引擎计算的里程计 |
| `/tf` | `tf2_msgs/msg/TFMessage` | `tf` | GZ → ROS | Gazebo 内部 TF 变换 |
| `/cmd_vel` | `geometry_msgs/msg/TwistStamped` | `cmd_vel` | ROS → GZ | 速度指令，控制机器人运动 |
| `/imu` | `sensor_msgs/msg/Imu` | `imu` | GZ → ROS | IMU 传感器数据 |
| `/scan` | `sensor_msgs/msg/LaserScan` | `scan` | GZ → ROS | LDS 激光雷达数据 |
| `/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | `camera/camera_info` | GZ → ROS | 相机内参（非 Burger 模型） |

**消息数据结构**：

```protobuf

Header header           # 时间戳和坐标系
float32 angle_min       # 起始角度 (rad)
float32 angle_max       # 结束角度 (rad)

```

```protobuf

Header header
string child_frame_id

TwistWithCovariance twist   # 速度 + 6x6 协方差矩阵
```

```protobuf
// geometry_msgs/msg/TwistStamped
Header header
Twist twist
  Vector3 linear    # linear.x = 线速度 (m/s)
  Vector3 angular   # angular.z = 角速度 (rad/s)
```

```protobuf
// sensor_msgs/msg/Imu

```

### 2.2 TurtleBot3 运动控制节点

#### 2.2.1 `turtlebot3_drive_node` (自动避障/探索)

| 属性 | 值 |
|------|-----|
| **包** | `turtlebot3_gazebo` |
| **源文件** | `src/turtlebot3_drive.cpp` |
| **作用** | 基于激光雷达数据的自主避障和探索驱动，实现 SLAM 自动建图 |

**订阅 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/scan` | `sensor_msgs/msg/LaserScan` | SensorDataQoS | 激光雷达数据，用于障碍物检测 |
| `/odom` | `nav_msgs/msg/Odometry` | KeepLast(10) | 里程计数据，获取当前偏航角 |

**发布 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/cmd_vel` | `geometry_msgs/msg/TwistStamped` | KeepLast(10) | 速度指令，控制机器人运动 |

**内部状态机**：

```
GET_TB3_DIRECTION (0)
    ├── 前方开阔 (inf_ratio > 0.7) → TB3_DRIVE_FORWARD
    │   └── 直行 30 次后 → 转向探索
    ├── 前方安全 (front_avg_dist > 1.2m) → 检查侧方
    │   ├── 左侧过近 → TB3_RIGHT_TURN
    │   ├── 右侧过近 → TB3_LEFT_TURN
    │   └── 两侧安全 → TB3_DRIVE_FORWARD
    └── 前方有障碍 → 比较左右距离
        ├── 左侧更开阔 → TB3_LEFT_TURN
        └── 右侧更开阔 → TB3_RIGHT_TURN
```

**关键参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `LINEAR_VELOCITY` | 0.3 m/s | 直行线速度 |
| `ANGULAR_VELOCITY` | 1.5 rad/s | 转向角速度 |
| `escape_range` | 30° | 转向角度阈值 |
| `check_forward_dist` | 1.2 m | 前方安全距离 |
| `check_side_dist` | 1.0 m | 侧方安全距离 |
| `inf_ratio` | 0.7 | 激光射线检测不到障碍的比例阈值 |

**更新频率**：10ms (100 Hz)

#### 2.2.2 `turtlebot3_fake_node` (仿真里程计)

| 属性 | 值 |
|------|-----|
| **包** | `turtlebot3_fake_node` |
| **源文件** | `src/turtlebot3_fake_node.cpp` |
| **作用** | 在没有 Gazebo 时提供仿真的里程计和关节状态（独立于 Gazebo 时使用） |

**订阅 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/cmd_vel` | `geometry_msgs/msg/Twist` 或 `TwistStamped` | KeepLast(10) | 速度指令（由参数 `enable_stamped_cmd_vel` 决定类型） |

**发布 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/odom` | `nav_msgs/msg/Odometry` | KeepLast(10) | 仿真里程计（运动学积分计算） |
| `/joint_states` | `sensor_msgs/msg/JointState` | KeepLast(10) | 左右轮关节状态 |
| `/tf` | `tf2_msgs/msg/TFMessage` | KeepLast(10) | odom → base_footprint 变换 |

**差速驱动运动学模型**：

```cpp
// 速度分解
wheel_speed_cmd[LEFT]  = goal_linear_velocity - (goal_angular_velocity * wheel_separation / 2)
wheel_speed_cmd[RIGHT] = goal_linear_velocity + (goal_angular_velocity * wheel_separation / 2)

// 里程计积分
delta_s = wheel_radius * (wheel_r + wheel_l) / 2.0        // 前进距离
delta_theta = wheel_radius * (wheel_r - wheel_l) / wheel_separation  // 转向角度

// 位姿更新
x += delta_s * cos(theta)
y += delta_s * sin(theta)
theta += delta_theta
```

**关键参数**（由 YAML 配置文件提供）：

| 参数 | Burger | Waffle/Waffle Pi | 说明 |
|------|--------|-------------------|------|
| `wheels.separation` | 0.160 m | 0.287 m | 左右轮间距 |
| `wheels.radius` | 0.033 m | 0.033 m | 轮子半径 |
| `joint_states_frame` | base_footprint | base_footprint | 关节状态帧 ID |
| `odom_frame` | odom | odom | 里程计帧 ID |
| `base_frame` | base_footprint | base_footprint | 基座帧 ID |

**更新频率**：10ms (100 Hz)
**cmd_vel 超时**：1.0 秒无指令则自动停止

**处理流程**：

```
LaserScan 回调
    ↓
通过 MessageFilter 获取匹配的 TF
    ↓
扫描匹配（相对于最近的关键位姿）
    ↓
添加到姿态图（Pose Graph）
    ↓
回环检测（距离阈值 loop_search_maximum_distance=3.0m）
    ↓
优化姿态图（Ceres Solver）
    ↓
发布 /map, pose, pose_graph, TF(map→odom)
```

### 2.4 DQN 强化学习节点

DQN 系统基于 TensorFlow/Keras 实现 Deep Q-Network，用于训练 TurtleBot3 在 Gazebo 仿真环境中自主导航避障。整个系统由 **6 个节点** 组成，通过 Service 和 Topic 协同工作。

#### 2.4.1 `dqn_environment` (RL 环境)

| 属性 | 值 |
|------|-----|
| **包** | `turtlebot3_dqn` |
| **源文件** | `turtlebot3_dqn/dqn_environment.py` |
| **节点名** | `rl_environment` |
| **作用** | 作为强化学习环境，订阅传感器数据，计算状态/奖励/完成信号，提供 Service 接口供训练/推理节点调用 |

**订阅 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/scan` | `sensor_msgs/msg/LaserScan` | SensorDataQoS | 激光雷达数据，用于障碍物检测和状态向量构建 |
| `/odom` | `nav_msgs/msg/Odometry` | KeepLast(10) | 里程计数据，计算到目标的距离和角度 |

**发布 Topic**：

| Topic | 消息类型 | QoS | 说明 |
|-------|----------|-----|------|
| `/cmd_vel` | `geometry_msgs/msg/Twist` (Humble) 或 `TwistStamped` (Jazzy+) | KeepLast(10) | 速度指令（线速度固定 0.2 m/s，角速度 5 种离散值） |

**提供的 Service**：

| Service | 服务类型 | 说明 |
|---------|----------|------|
| `rl_agent_interface` | `turtlebot3_msgs/srv/Dqn` | 核心接口：执行动作并返回状态/奖励/完成信号 |
| `make_environment` | `std_srvs/srv/Empty` | 初始化整个环境（触发 Gazebo 初始化） |
| `reset_environment` | `turtlebot3_msgs/srv/Dqn` | 重置环境并返回初始状态 |

**`Dqn` Service 消息结构**：

```protobuf
// turtlebot3_msgs/srv/Dqn - Request
uint8 action    // 0-4，对应 5 个角速度动作
bool init       // 是否为初始步骤（测试模式使用）

// turtlebot3_msgs/srv/Dqn - Response
float32[] state  // 26 维状态向量: [goal_distance, goal_angle, 24个LiDAR射线值]
float32 reward   // 当前步奖励值
bool done        // 回合是否结束（到达目标/碰撞/超时）
```

**状态向量构建**：
- `state[0]` = 到目标的距离（m）
- `state[1]` = 到目标的角度（rad）
- `state[2:26]` = 24 个均匀分布的 LiDAR 射线距离值（从 360° 中采样）

**奖励函数设计**：

| 奖励类型 | 公式/值 | 说明 |
|----------|---------|------|
| 方向奖励 (yaw_reward) | `1 - 2 * \|goal_angle\| / π` | 范围 [-1, 1]，朝向目标时最大 |
| 障碍物奖励 (obstacle_reward) | `-(1.0 + 4.0 * weighted_decay)` | 基于 0.5m 范围内障碍物的方向加权指数衰减惩罚 |
| 成功奖励 | **+100.0** | 到达目标距离 < 0.20 m |
| 失败惩罚 | **-50.0** | 碰撞距离 < 0.15 m 或超时（> 800 步） |

**关键参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_step` | 800 | 每回合最大步数（超时判定失败） |
| 目标到达距离 | < 0.20 m | 判定成功的距离阈值 |
| 碰撞距离 | < 0.15 m | 判定失败的距离阈值 |
| 障碍感知阈值 | <= 0.5 m | 计算方向性障碍奖励的范围 |

#### 2.4.2 `dqn_agent` (DQN 训练节点)

| 属性 | 值 |
|------|-----|
| **源文件** | `turtlebot3_dqn/dqn_agent.py` |
| **节点名** | `dqn_agent` |
| **作用** | 构建 Q 网络，执行 epsilon-greedy 策略，经验回放，梯度训练 |

**调用的 Service**：

| Service | 服务类型 | 说明 |
|---------|----------|------|
| `rl_agent_interface` | `turtlebot3_msgs/srv/Dqn` | 发送动作 (action 0-4)，接收状态/奖励/完成信号 |
| `make_environment` | `std_srvs/srv/Empty` | 初始化环境 |
| `reset_environment` | `turtlebot3_msgs/srv/Dqn` | 每回合开始时重置环境 |

**发布 Topic**：

| Topic | 消息类型 | 说明 |
|-------|----------|------|
| `/get_action` | `std_msgs/msg/Float32MultiArray` | 实时动作信息: `[action, score, reward]` |
| `result` | `std_msgs/msg/Float32MultiArray` | 训练结果: `[score, avg_max_q]` |

**Q 网络结构**：

```
Input(26) → Dense(512, relu) → Dense(256, relu) → Dense(128, relu) → Dense(5, linear)
```

- 优化器: Adam (lr=0.0007)
- 损失函数: MSE

**训练流程**：
```
1. 调用 reset_environment 获取初始状态 state[26]
2. Epsilon-greedy 选择动作 action (0-4)
3. 调用 rl_agent_interface(action) 获取 state', reward, done
4. 将 (state, action, reward, state', done) 存入经验回放池
5. 从回放池采样 batch_size=128 条经验
6. 计算 TD 目标: r + γ * max Q(s', a')
7. 反向传播更新 Q 网络
8. 每 5000 步更新目标网络
9. 衰减 epsilon: ε = ε_min + (1 - ε_min) * exp(-step / epsilon_decay)
```

**关键参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `state_size` | 26 | 状态维度: 2(目标) + 24(LiDAR) |
| `action_size` | 5 | 5 个离散角速度动作 |
| `angular_vel` | `[1.5, 0.75, 0.0, -0.75, -1.5]` | 角速度值 (rad/s)，线速度固定 0.2 m/s |
| `discount_factor` (γ) | 0.99 | Q-learning 折扣因子 |
| `learning_rate` | 0.0007 | Adam 优化器学习率 |
| `epsilon` | 1.0 | 初始探索率 |
| `epsilon_min` | 0.05 | 最小探索率 |
| `epsilon_decay` | 6000 | 探索率衰减半衰期 |
| `batch_size` | 128 | 经验回放批次大小 |
| `replay_memory` | 500,000 | 经验回放缓冲区容量 |
| `min_replay_memory_size` | 5,000 | 开始训练前的最小样本数 |
| `max_training_episodes` | 1000 | 最大训练回合数 |
| `update_target_after` | 5000 | 目标网络更新间隔步数 |

**可通过 `ros2 param set` 修改的运行时参数**：
- `epsilon_decay` (int)
- `max_training_episodes` (int)
- `model_file` (string) — 预训练模型文件名
- `use_gpu` (bool)
- `verbose` (bool)

## 三、坐标系 (TF) 关系

```
                    map (SLAM 发布)
                     │
                     │ map → odom TF
                     │ (由 SLAM 校正)
                     ▼
                    odom (Gazebo 或 FakeNode 发布)
                     │
                     │ odom → base_footprint TF
                     │ (由物理引擎或运动学积分)
                     ▼
               base_footprint
                     │
        ┌────────────┼────────────┐
        │            │            │
        ▼            ▼            ▼
   base_link   imu_link    base_scan
        │                              ← LDS 激光雷达坐标系
   wheel_left
   wheel_right
   caster_back
```

| TF 变换 | 发布者 | 说明 |
|---------|--------|------|
| `map → odom` | `slam_toolbox` | SLAM 校正的全局位姿变换 |
| `odom → base_footprint` | Gazebo / `turtlebot3_fake_node` | 里程计累积的局部位姿 |
| `base_footprint → base_link` | `robot_state_publisher` | 底盘主体位置 |
| `base_link → base_scan` | `robot_state_publisher` | 激光雷达安装位置 |
| `base_link → imu_link` | `robot_state_publisher` | IMU 安装位置 |
| `base_link → wheel_left/right_link` | `robot_state_publisher` | 轮子位置 |

### 4.3 DQN 强化学习训练流程

```
时间线:
─────────────────────────────────────────────────────────────────────

T+0s    Gazebo 启动 (turtlebot3_dqn_stage{1-4}.launch.py)
        ├── Gazebo Sim 加载 DQN 世界
        ├── ros_gz_bridge 桥接话题
        └── robot_state_publisher 发布 TF

T+0s    dqn_environment 启动
        ├── 订阅 /scan, /odom
        ├── 发布 /cmd_vel
        ├── 提供 rl_agent_interface, make_environment, reset_environment
        └── 等待初始化

T+1s    dqn_gazebo 启动
        ├── 提供 initialize_env, task_succeed, task_failed
        └── 准备 spawn/delete goal_box

T+2s    dqn_agent 启动
        ├── 构建 Q 网络: Input(26) → Dense(512) → Dense(256) → Dense(128) → Dense(5)
        ├── epsilon = 1.0, replay_memory = []
        └── 开始训练

        ┌─────────────────────────────────────────────────────────────────┐
        │  Episode 循环 (max 1000):                                       │
        │                                                                 │
        │  1. 调用 make_environment → 初始化环境                          │
        │  2. 调用 reset_environment → 获取初始状态 state[26]             │
        │  3. 调用 initialize_env → dqn_gazebo 生成目标                   │
        │                                                                 │
        │  ┌─────────────────────────────────────────────────────────┐   │
        │  │  Step 循环 (max 800):                                    │   │
        │  │                                                         │   │
        │  │  4. Epsilon-greedy 选择动作 action (0-4)                │   │
        │  │     - ε 概率: 随机动作 (探索)                           │   │
        │  │     - (1-ε) 概率: argmax(Q(state)) (利用)               │   │
        │  │                                                         │   │
        │  │  5. 调用 rl_agent_interface(action)                     │   │
        │  │         ↓ dqn_environment:                               │   │
        │  │         - 解析 action → 角速度 angular_vel[action]       │   │
        │  │         - 发布 /cmd_vel (linear=0.2, angular=selected)   │   │
        │  │         - Gazebo 物理仿真 → 机器人移动                    │   │
        │  │         - 解析 /scan → 24 个 LiDAR 射线                  │   │
        │  │         - 解析 /odom → goal_distance, goal_angle         │   │
        │  │         - 计算奖励 = yaw_reward + obstacle_reward        │   │
        │  │         - 检查 done: 到达/碰撞/超时                       │   │
        │  │         - 返回 state', reward, done                      │   │
        │  │                                                         │   │
        │  │  6. 存储经验 (state, action, reward, state', done)       │   │
        │  │                                                         │   │
        │  │  7. if len(replay_memory) >= 5000:                      │   │
        │  │       - 采样 batch_size=128                              │   │
        │  │       - 计算 TD 目标: r + 0.99 * max Q(s', a')          │   │
        │  │       - 反向传播更新 Q 网络 (Adam, lr=0.0007)           │   │
        │  │       - 每 5000 步更新目标网络                           │   │
        │  │                                                         │   │
        │  │  8. 发布 /get_action [action, score, reward]             │   │
        │  │         ↓ action_graph 显示 Q 值进度条                   │   │
        │  │                                                         │   │
        │  │  9. if done:                                            │   │
        │  │       - 成功 (到达目标):                                  │   │
        │  │         调用 task_succeed → dqn_gazebo 生成新目标        │   │
        │  │       - 失败 (碰撞/超时):                                 │   │
        │  │         调用 task_failed → dqn_gazebo 仿真重置           │   │
        │  │       - 发布 result [score, avg_max_q]                   │   │
        │  │         ↓ result_graph 绘制训练曲线                      │   │
        │  │       - break 进入下一 Episode                           │   │
        │  │                                                         │   │
        │  └─────────────────────────────────────────────────────────┘   │
        │                                                                 │
        │  10. 衰减 epsilon: ε = 0.05 + 0.95 * exp(-episode / 6000)      │
        └─────────────────────────────────────────────────────────────────┘

T+结束  保存模型到 saved_model/ 目录

─────────────────────────────────────────────────────────────────────
```
