## 添加新的仿真世界

### 步骤 1: 创建世界文件

在 `turtlebot3_gazebo/worlds/` 下创建 `.world` 文件：

```xml
<?xml version="1.0" ?>
<sdf version="1.7">
  <world name="my_world">
    <include>
      <uri>package://turtlebot3_gazebo/models/turtlebot3_world/model.sdf</uri>
    </include>
    
    <!-- 添加模型 -->
    <include>
      <uri>package://turtlebot3_gazebo/models/obstacle/model.sdf</uri>
      <pose>2 0 0 0 0 0</pose>
    </include>
    
    <scene>
      <ambient>0.8 0.8 0.8 1</ambient>
      <background>0.7 0.7 0.7 1</background>
      <grid>true</grid>
    </scene>
    
    <physics name="1ms" type="ode">
      <max_step_size>0.001</max_step_size>
      <real_time_factor>1</real_time_factor>
    </physics>
  </world>
</sdf>
```

### 步骤 2: 创建启动文件

在 `turtlebot3_gazebo/launch/` 下创建 `my_world.launch.py`：

```python
import os
from launch import LaunchDescription
from launch.actions import ExecuteProcess, IncludeLaunchDescription, RegisterEventHandler
from launch.event_handlers import OnProcessExit
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare

def generate_launch_description():
    pkg_turtlebot3_gazebo = FindPackageShare('turtlebot3_gazebo')
    
    return LaunchDescription([
        # 启动 Gazebo
        IncludeLaunchDescription(
            PythonLaunchDescriptionSource([
                PathJoinSubstitution([pkg_turtlebot3_gazebo, 'launch', 'spawn_turtlebot3.launch.py'])
            ])
        ),
        
        # 启动 world
        ExecuteProcess(
            cmd=['ros2', 'launch', 'ros_gz_sim', 'gz_sim.launch.py', 
                 'gz_args', ['-r ', os.path.join(pkg_turtlebot3_gazebo, 'worlds', 'my_world.world')]],
            output='screen'
        ),
    ])
```

### 步骤 3: 更新管理脚本

在 `turtlebot3_simulations.sh` 中添加：


## 开发 ROS 2 节点

### Python 节点

创建 `src/my_package/my_package/my_node.py`：

```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan

class MyNode(Node):
    def __init__(self):
        super().__init__('my_node')
        self.publisher = self.create_publisher(Twist, 'cmd_vel', 10)
        self.subscription = self.create_subscription(
            LaserScan, 'scan', self.scan_callback, 10)
        self.timer = self.create_timer(0.1, self.timer_callback)
    
    def scan_callback(self, msg):
        # 处理激光雷达数据
        self.get_logger().info(f'Min distance: {min(msg.ranges)}')
    
    def timer_callback(self):
        # 发布速度命令
        msg = Twist()
        msg.linear.x = 0.1
        self.publisher.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    node = MyNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### C++ 节点

创建 `src/my_package/src/my_node.cpp`：

```cpp
#include <rclcpp/rclcpp.hpp>
#include <geometry_msgs/msg/twist.hpp>
#include <sensor_msgs/msg/laser_scan.hpp>

class MyNode : public rclcpp::Node
{
public:
  MyNode() : Node("my_node")
  {
    publisher_ = this->create_publisher<geometry_msgs::msg::Twist>("cmd_vel", 10);
    subscription_ = this->create_subscription<sensor_msgs::msg::LaserScan>(
      "scan", 10, std::bind(&MyNode::scan_callback, this, std::placeholders::_1));
    timer_ = this->create_wall_timer(
      std::chrono::milliseconds(100), std::bind(&MyNode::timer_callback, this));
  }

private:
  void scan_callback(const sensor_msgs::msg::LaserScan::SharedPtr msg)
  {
    RCLCPP_INFO(this->get_logger(), "Min distance: %f", *std::min_element(msg->ranges.begin(), msg->ranges.end()));
  }

  void timer_callback()
  {
    auto msg = geometry_msgs::msg::Twist();
    msg.linear.x = 0.1;
    publisher_->publish(msg);
  }

  rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr publisher_;
  rclcpp::Subscription<sensor_msgs::msg::LaserScan>::SharedPtr subscription_;
  rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char * argv[])
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<MyNode>());
  rclcpp::shutdown();
  return 0;
}
```

## 常见问题

### Q: 如何修改仿真中的机器人位置

**A**: 在启动文件中使用参数：

```python
Node(
    package='ros_gz_sim',
    executable='create',
    arguments=[
        '-name', 'turtlebot3',
        '-x', '1.0',
        '-y', '2.0',
        '-z', '0.0',
    ],
)
```

### Q: 如何添加自定义模型

**A**: 在 `models/` 下创建模型目录，添加 `model.sdf` 和 `model.config` 文件。

### Q: 如何优化仿真性能

**A**: 
1. 降低 Gazebo 更新频率
2. 减少 LiDAR 扫描点数
3. 使用 Fake Node 代替完整仿真
4. 关闭不必要的传感器
