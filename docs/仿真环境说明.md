# 仿真环境说明

## Gazebo 仿真世界

### 1. Empty World（空世界）

**文件**: `worlds/empty_world.world`

最简单的仿真环境，适合：
- 基础功能测试
- 算法快速验证
- 无干扰环境开发

**启动命令**:
```bash
./turtlebot3_simulations.sh empty_world
```

### 2. TurtleBot3 World

**文件**: `worlds/turtlebot3_world.world`

包含六边形墙壁和障碍物的导航测试环境，适合：
- SLAM 算法测试
- 路径规划验证
- 避障算法开发

**特点**:
- 六边形墙壁结构
- 静态障碍物
- 适合 2D SLAM（Cartographer, Gmapping）

**启动命令**:
```bash
./turtlebot3_simulations.sh turtlebot3_world
```

### 3. TurtleBot3 House

**文件**: `worlds/turtlebot3_house.world`

室内家居环境，包含：
- 多房间布局
- 家具（桌子、邮箱、垃圾桶等）
- 门和走廊

**适合**:
- 室内导航测试
- 复杂环境 SLAM
- 家具避障测试

**启动命令**:
```bash
./turtlebot3_simulations.sh turtlebot3_house
```

### 4. DQN Training Stages

**文件**: `worlds/turtlebot3_dqn_stage1.world` ~ `stage4.world`

4 个渐进式强化学习训练场景：

| 阶段 | 复杂度 | 障碍物 | 用途 |
|------|--------|--------|------|
| Stage 1 | ★☆☆☆ | 简单 | 基础避障 |
| Stage 2 | ★★☆☆ | 中等 | 动态障碍 |
| Stage 3 | ★★★☆ | 复杂 | 多障碍 |
| Stage 4 | ★★★★ | 极复杂 | 高级训练 |

**特点**:
- 旋转障碍物（`obstacles` 插件）
- 移动障碍物（`obstacle1/2` 插件）
- 目标区域（`goal_box` 模型）
- 适合 DQN、PPO 等强化学习算法

**启动命令**:
```bash
./turtlebot3_simulations.sh dqn_stage1
./turtlebot3_simulations.sh dqn_stage2
./turtlebot3_simulations.sh dqn_stage3
./turtlebot3_simulations.sh dqn_stage4
```

## 仿真插件

### 旋转障碍物插件 (obstacles)

**源代码**: `src/obstacles.cpp`

**功能**:
- 360 度旋转模型
- 旋转周期：80 秒/圈
- 用于 DQN 场景

**关键代码**:
```cpp
void Update() {
  angle += 0.001 * dt;  // 80秒转360度
  if (angle > 2 * M_PI) angle -= 2 * M_PI;
  model->SetLocalRotation(common::Quaternion(0, 0, angle));
}
```

### 移动障碍物插件 (obstacle1/2)

**源代码**: `src/obstacle1.cpp`, `src/obstacle2.cpp`

**功能**:
- 沿预设路径点移动
- 速度：0.1 m/s
- 循环运动

**路径点**:
- obstacle1: 7 个路径点
- obstacle2: 11 个路径点

### 交通灯插件 (traffic_light_plugin)

**源代码**: `src/traffic_light_plugin.cpp`

**功能**:
- 交通灯纹理切换
- 周期：绿灯 5s → 黄灯 1s → 红灯 5s
- 用于 Autorace 场景

**注意**: 这是 Gazebo Classic 插件，不是 GZ Sim 插件

### 栏杆插件 (traffic_bar_plugin)

**源代码**: `src/traffic_bar_plugin.cpp`

**功能**:
- 栏杆臂上下移动
- 周期：每 10 秒切换
- 用于 Autorace 场景

## 机器人模型 (URDF)

### Burger

**文件**: `urdf/turtlebot3_burger.urdf`

**参数**:
- 轮距：0.160m
- 轮半径：0.033m
- 传感器：LDS-01 LiDAR + IMU

**特点**: 最紧凑的模型，适合室内导航

### Burger + Cam

**文件**: `urdf/turtlebot3_burger_cam.urdf`

**参数**: 同 Burger + RGB 摄像头

**特点**: 增加视觉传感器，适合视觉 SLAM

### Waffle

**文件**: `urdf/turtlebot3_waffle.urdf`

**参数**:
- 轮距：0.287m
- 轮半径：0.033m
- 传感器：LiDAR + IMU + Intel R200 深度相机

**特点**: 更大的平台，更强的传感器

### Waffle Pi

**文件**: `urdf/turtlebot3_waffle_pi.urdf`

**参数**: 同 Waffle + RGB 相机（无深度）

**特点**: 简化版 Waffle，适合视觉导航

## 桥接配置 (YAML)

### 桥接主题

所有机器人模型的桥接配置位于 `params/` 目录：

| 文件 | 桥接主题 |
|------|----------|
| `turtlebot3_burger_bridge.yaml` | clock, joint_states, odom, tf, cmd_vel, imu, scan |
| `turtlebot3_burger_cam_bridge.yaml` | 同上 + camera, camera_info |
| `turtlebot3_waffle_bridge.yaml` | 同上 + camera, camera_info |
| `turtlebot3_waffle_pi_bridge.yaml` | 同上 + camera, camera_info |

### 桥接配置示例

```yaml
- ros_topic_name: "scan"
  gz_topic_name: "scan"
  ros_type_name: "sensor_msgs/msg/LaserScan"
  gz_type_name: "gz.msgs.LaserScan"
  direction: GZ_TO_ROS

- ros_topic_name: "cmd_vel"
  gz_topic_name: "cmd_vel"
  ros_type_name: "geometry_msgs/msg/TwistStamped"
  gz_type_name: "gz.msgs.Twist"
  direction: ROS_TO_GZ
```

## Fake Node 仿真

### 工作原理

Fake Node 是一个**无物理引擎**的轻量级仿真节点：

```
/cmd_vel (输入)
    │
    ▼
┌─────────────────────────┐
│   TurtleBot3 Fake Node   │
│                          │
│  运动学计算:              │
│  v_left = (v - ω*L/2)/r  │
│  v_right = (v + ω*L/2)/r │
│                          │
│  位姿积分:                │
│  x += Δs * cos(θ)        │
│  y += Δs * sin(θ)        │
│  θ += Δθ                 │
└─────────────────────────┘
    │
    ├──► /odom (输出)
    ├──► /joint_states (输出)
    └──► TF 变换 (base_link → odom)
```

### 参数配置

**文件**: `param/burger.yaml`, `param/waffle.yaml`, `param/waffle_pi.yaml`

```yaml
turtlebot3_fake_node:
  ros__parameters:
    wheels:
      separation: 0.160  # Burger
      radius: 0.033
    frame_id: "base_footprint"
```

### 使用场景

1. **算法快速验证**: 无需启动完整 Gazebo
2. **RViz 测试**: 验证可视化和 TF 变换
3. **运动学测试**: 测试控制算法
4. **开发环境**: 资源受限时的替代方案

### 限制

- ❌ 无物理引擎（无碰撞检测）
- ❌ 无传感器仿真（无 LiDAR、Camera 数据）
- ❌ 无世界模型
- ✅ 运动学仿真
- ✅ TF 变换
- ✅ 里程计输出

## 自动避障节点

**可执行文件**: `turtlebot3_drive`

**源代码**: `src/turtlebot3_drive.cpp`

### 工作原理

```
订阅 /scan
    │
    ▼
┌─────────────────────┐
│  读取 3 个角度数据    │
│  - 中心 (0°)         │
│  - 左 (30°)          │
│  - 右 (330°)         │
└─────────────────────┘
    │
    ▼
┌─────────────────────┐
│  状态机              │
│                      │
│  DRIVE_FORWARD       │  前进，无障碍
│  RIGHT_TURN          │  右侧障碍，右转
│  LEFT_TURN           │  左侧障碍，左转
└─────────────────────┘
    │
    ▼
发布 /cmd_vel
```

### 参数

| 参数 | 值 |
|------|-----|
| 线速度 | 0.3 m/s |
| 角速度 | 1.5 rad/s |
| 检测角度 | 0°, 30°, 330° |

### 启动方式

```bash
# 先启动仿真世界
./turtlebot3_simulations.sh turtlebot3_world

# 然后启动避障节点
./turtlebot3_simulations.sh turtlebot3_drive
```
