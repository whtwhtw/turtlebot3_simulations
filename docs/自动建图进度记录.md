## 三、完整启动流程

### 方法一: 使用管理脚本 (推荐)

```bash
cd /media/wht/J/Auto-driving/slam/仿真SLAM/turtlebot3_simulations

# 1. 启动/创建容器
bash turtlebot3_simulations.sh start

# 2. 编译项目 (首次或修改代码后)
bash turtlebot3_simulations.sh build

# 3. 启动 Gazebo house 场景
bash turtlebot3_simulations.sh turtlebot3_house

# 4. 启动自动 SLAM (Cartographer + turtlebot3_drive)
bash turtlebot3_simulations.sh auto_slam

# 5. 启动 RViz 可视化
bash turtlebot3_simulations.sh rviz

# 6. 保存地图 (建图完成后)
bash turtlebot3_simulations.sh save_map my_house_map
```

### 方法二: 手动在容器内启动

```bash
# 进入容器
docker exec -it turtlebot3-sim bash

# 环境准备
export TURTLEBOT3_MODEL=burger
export GZ_SIM_RESOURCE_PATH=/workspace/turtlebot3_gazebo/models
source /opt/ros/jazzy/setup.bash
cd /root/turtlebot3_ws && source install/setup.bash

# 1. 启动 Gazebo + house 场景
ros2 launch turtlebot3_gazebo turtlebot3_house.launch.py

# 2. (新终端) 启动 auto_slam
source /opt/ros/jazzy/setup.bash && source /root/turtlebot3_ws/install/setup.bash
ros2 launch turtlebot3_gazebo auto_slam.launch.py use_rviz:=false

# 3. (新终端) 启动 RViz
source /opt/ros/jazzy/setup.bash && source /root/turtlebot3_ws/install/setup.bash
rviz2 -d /root/turtlebot3_ws/install/turtlebot3_gazebo/share/turtlebot3_gazebo/rviz/tb3_gazebo.rviz
```

## 七、常见问题与解决

### 7.1 Gazebo 启动后看不到窗口

**症状**: Gazebo 进程在运行但没有可见窗口

**原因**: DISPLAY 环境变量不匹配

**解决**:
```bash
# 检查宿主机 DISPLAY
echo $DISPLAY  # 通常是 :0 或 :1

# 检查容器内 DISPLAY
docker exec turtlebot3-sim bash -c 'echo $DISPLAY'

# 必须一致！如果不一致，重启容器让它自动检测
docker restart turtlebot3-sim
```

### 7.2 RViz 中没有地图显示

**症状**: RViz 启动但看不到地图

**可能原因**:
1. Fixed Frame 不是 `map` (需要是 `map`)
2. Map 显示没有添加到 RViz
3. `/map` 话题数据全是 `-1` (未知区域，建图尚未开始)

**解决**:
- 在 RViz 中设置 Global Options → Fixed Frame = `map`
- 点击 Add → Map → Topic 选 `/map`
- 检查 `/map` 话题是否有有效数据: `ros2 topic echo /map --once`

### 7.3 Gazebo 启动了多个实例

**症状**: 多个 Gazebo 窗口，资源占用高

**解决**: 彻底重启容器
```bash
docker restart turtlebot3-sim
sleep 5
# 然后只用一个终端启动 Gazebo
bash turtlebot3_simulations.sh turtlebot3_house
```

### 7.4 后台启动的命令退出后进程消失

**原因**: `docker exec -it` 在后台运行时 `-it` 标志会导致问题

**解决**: 使用 `docker exec -d` (detached 模式)
```bash
docker exec -d turtlebot3-sim bash -c "source /opt/ros/jazzy/setup.bash && ros2 launch ..."
```

### 7.5 cartographer_occupancy_grid_node 节点找不到

**症状**: `ros2 node info cartographer_occupancy_grid_node` 报 "Unable to find node"

**解决**: 使用完整节点名
```bash
ros2 node info /cartographer_occupancy_grid_node
```

## 八、地图保存

```bash
# 使用 nav2_map_server 保存地图
docker exec turtlebot3-sim bash -c "
    source /opt/ros/jazzy/setup.bash &&
    source /root/turtlebot3_ws/install/setup.bash &&
    cd /root/turtlebot3_ws &&
    mkdir -p maps &&
    ros2 run nav2_map_server map_saver_cli -f maps/my_map --fmt png --ros-args -p save_map_timeout:=10000.0
"
```

输出文件:
- `maps/my_map.pgm` - 地图图像
- `maps/my_map.yaml` - 地图元数据 (分辨率、原点等)
