# 项目概述

## 项目简介

本项目是 ROBOTIS 官方 [turtlebot3_simulations](https://github.com/ROBOTIS-GIT/turtlebot3_simulations) 的 ROS 2 Humble 版本，提供完整的 TurtleBot3 机器人仿真环境。

**版本**: 2.3.7  
**ROS 发行版**: Humble / Rolling / Jazzy  
**许可证**: Apache 2.0

## 包说明

### 1. turtlebot3_gazebo - Gazebo 仿真

核心 Gazebo 仿真环境包，提供：

- **多种仿真世界**:
  - `empty_world` - 空世界，基础测试
  - `turtlebot3_world` - SLAM/导航世界
  - `turtlebot3_house` - 室内家居环境
  - `turtlebot3_dqn_stage1-4` - DQN 强化学习训练场景

- **Gazebo 插件**:
  - `obstacles` - 360度旋转障碍物
  - `obstacle1/2` - 沿路径移动的障碍物
  - `traffic_light_plugin` - 交通灯（Autorace）
  - `traffic_bar_plugin` - 栏杆（Autorace）

- **自动避障节点** (`turtlebot3_drive`):
  - 基于激光雷达数据的简单避障算法
  - 状态机：DRIVE_FORWARD → RIGHT_TURN → LEFT_TURN
  - 线速度 0.3 m/s，角速度 1.5 rad/s

### 2. turtlebot3_fake_node - 轻量级 RViz 仿真

无需 Gazebo 的轻量级仿真节点：

- 模拟 TurtleBot3 运动学
- 订阅 `/cmd_vel`，发布 `/odom`、`/joint_states`、TF 变换
- 100Hz 更新频率
- 1秒无命令自动停止
- 适合快速算法验证和 RViz 测试

### 3. turtlebot3_simulations - Meta-package

聚合包，无实际代码，仅声明对以上两个包的依赖。

## 支持的机器人模型

| 模型 | 轮距 | 轮半径 | 传感器 |
|------|------|--------|--------|
| **Burger** | 0.160m | 0.033m | LiDAR + IMU |
| **Burger+Cam** | 0.160m | 0.033m | LiDAR + IMU + RGB Camera |
| **Waffle** | 0.287m | 0.033m | LiDAR + IMU + Depth Camera (R200) |
| **Waffle Pi** | 0.287m | 0.033m | LiDAR + IMU + RGB Camera |

通过环境变量 `TURTLEBOT3_MODEL` 选择模型：
```bash
export TURTLEBOT3_MODEL=burger
```

## 技术栈

- **构建系统**: ament_cmake
- **编程语言**: C++17
- **Gazebo 版本**: GZ Sim (Gazebo Garden)
- **桥接**: ros_gz_bridge, ros_gz_image, ros_gz_sim
- **核心依赖**: rclcpp, geometry_msgs, nav_msgs, sensor_msgs, tf2

### 差速驱动运动学

```
轮速计算:
v_left  = (linear_x - angular_z * wheel_separation / 2) / wheel_radius
v_right = (linear_x + angular_z * wheel_separation / 2) / wheel_radius

位姿积分:
delta_s     = (v_left + v_right) * wheel_radius / 2 * dt
delta_theta = (v_right - v_left) * wheel_radius / wheel_separation * dt
```

## 应用场景

1. **SLAM 算法开发**: 使用 turtlebot3_world 进行建图和定位
2. **导航算法**: 在仿真环境中测试路径规划和避障
3. **强化学习**: DQN 场景训练障碍物避免策略
4. **快速原型**: Fake Node 无需完整仿真即可验证算法
5. **教学演示**: 多种场景适合教学和演示
